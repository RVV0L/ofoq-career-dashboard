# Career Progress Tracker — Design System Master

## 1. Product Profile & Dials
- **Domain**: Academic & Career Progress Dashboard + Public Technical Portfolio (RTL Arabic + LTR Technical Tokens)
- **Stack**: React 18 + Vite 5 + Tailwind CSS 3 + Recharts + Framer Motion + Lucide Icons
- **Style Priority**: Linear / Precision Dark (Dark Mode) + Clean Enterprise / High-Trust (Light Mode) + Bento Grid
- **Design Dials**:
  - `--variance`: 5/10
  - `--motion`: 4/10
  - `--density`: 7/10
